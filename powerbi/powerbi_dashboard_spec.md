## 1. Data Model & Architecture

All data files are generated by `powerbi/05_powerbi_export.ipynb` directly into `powerbi/data/`.

### Tables Overview

| Table | File Name | Type | Purpose |
| :--- | :--- | :---: | :--- |
| **`dim_teams`** | `dim_teams.csv` | Dimension | 30 teams: Team Abbreviation, Full Name, Conference, Division, Primary Hex Color, Secondary Hex Color |
| **`fact_team_projections`** | `fact_team_projections.csv` | Fact | 30 teams: Projected Wins, Losses, Win %, Final Power Score, Playoff %, Conf Finals %, Finals %, Championship % |
| **`fact_seed_distribution`** | `fact_seed_distribution.csv` | Fact | 300 rows (30 teams × 10 seeds): Probability of finishing in each seed (1–10) |
| **`fact_win_distribution`** | `fact_win_distribution.csv` | Fact | 30 teams: Min, P10, P25, Median, Mean, P75, P90, Max, Std Dev simulated wins |
| **`fact_finals_matchups`** | `fact_finals_matchups.csv` | Fact | Top 25 most frequent NBA Finals pairings (East Champion vs. West Champion) |
| **`fact_sample_bracket`** | `fact_sample_bracket.csv` | Fact | 15 postseason series from a complete simulated universe: Stage, Higher Seed, Lower Seed, Series Score, Game 7 (True/False), Winner |
| **`fact_model_metrics`** | `fact_model_metrics.csv` | Fact | Model validation metrics: Logistic Regression, Random Forest, XGBoost (Accuracy, ROC-AUC) |
| **`fact_roster_players`** | `fact_roster_players.csv` | Fact | ~270 rotation players: Player Name, Team, AVG_MIN, RAW_GmSc, Shrunk Value, VORP, Team Rank |

### Power BI Relationships (Star Schema)

In the **Model View** of Power BI Desktop, connect:
- `dim_teams[TEAM]` `1` ──── `*` `fact_team_projections[TEAM]` (Single direction)
- `dim_teams[TEAM]` `1` ──── `*` `fact_seed_distribution[TEAM]` (Single direction)
- `dim_teams[TEAM]` `1` ──── `*` `fact_win_distribution[TEAM]` (Single direction)
- `dim_teams[TEAM]` `1` ──── `*` `fact_roster_players[TEAM]` (Single direction)
- `dim_teams[TEAM]` `1` ──── `*` `fact_sample_bracket[WINNER]` (Active)
- `dim_teams[TEAM]` `1` ──── `*` `fact_sample_bracket[HIGH_SEED]` (Inactive)
- `dim_teams[TEAM]` `1` ──── `*` `fact_sample_bracket[LOW_SEED]` (Inactive)

## 2. Color Palette & Typography

To replicate the clean, modern look of the reference dashboard while honoring the NBA brand:

- **Primary Background Canvas:** Light Gray / Off-White (`#F4F6F9`)
- **Card Background:** Pure White (`#FFFFFF`) with subtle border (`#E2E8F0`) and 2px drop shadow
- **NBA Primary Blue:** `#1D428A` (Header, card labels, primary brand banner)
- **NBA Trophy Gold:** `#FDB927` / `#C99700` (Champion highlights, trophy accents)
- **Bar Chart Fill:** Bright Blue (`#2B6CB0` or `#1E88E5`) matching the FIFA chart in the reference
- **Donut Chart Palette:** High-contrast category colors (`#1D428A`, `#0C2340`, `#E03A3E`, `#007A33`, `#552583`, `#002B5C`, `#CE1141`, `#008348`)
- **Typography:**
  - Headers: **Segoe UI Semibold** (or **DIN**, if available)
  - KPI Callouts: **Segoe UI Bold** (24pt – 28pt)
  - Data Labels / Tables: **Segoe UI Regular** (9pt – 11pt)

## 3. Key DAX Measures

Create a dedicated table named `_Measures` in Power BI:

```dax
// 1. Projected Champion Name
Projected Champion = 
CALCULATE(
    FIRSTNONBLANK(fact_team_projections[FULL_NAME], 1),
    TOPN(1, ALL(fact_team_projections), fact_team_projections[CHAMPIONSHIP_PROB], DESC)
)

// 2. Projected Champion Win Probability
Projected Champion Odds = 
CALCULATE(
    MAX(fact_team_projections[CHAMPIONSHIP_PROB]),
    TOPN(1, ALL(fact_team_projections), fact_team_projections[CHAMPIONSHIP_PROB], DESC)
)

// 3. Total Simulations Label
Total Simulations = "10K"

// 4. Total Regular Season Matches
Total Matches = "1,230"

// 5. Model Accuracy (from best model: Logistic Regression)
Model Accuracy = 
CALCULATE(
    MAX(fact_model_metrics[Accuracy]),
    fact_model_metrics[Model] = "Logistic Regression"
)

// 6. Model ROC-AUC
Model ROC-AUC = 
CALCULATE(
    MAX(fact_model_metrics[ROC_AUC]),
    fact_model_metrics[Model] = "Logistic Regression"
)

// 7. Simulated Titles Count
Simulated Titles = SUM(fact_team_projections[TITLES_WON])

// 8. Formatted Win Record
Projected Record = 
SELECTEDVALUE(fact_team_projections[PROJ_WINS_FORMATTED]) & " - " & SELECTEDVALUE(fact_team_projections[PROJ_LOSSES_FORMATTED])
```

## 4. Page 1: Championship Overview (Reference Match)

### Visual 1: Top Navigation Banner
- **Text Box / Banner Shape:** Background `#1D428A` or White with Blue text.
- **Title (20pt Bold, White or Navy):** `2026-27 NBA CHAMPIONSHIP PREDICTION DASHBOARD`
- **Subtitle (11pt Regular, Light Gold/Gray):** `Machine Learning | 10,000 Monte Carlo Simulations | Power BI`

### Visual 2: Five Top KPI Cards (Horizontal Alignment)
Place 5 Card visuals side-by-side with White backgrounds and rounded borders (padding: 4px):
1. **Card 1 (Champion):** Measure `[Projected Champion]`. Sub-label: `Projected Champion 🏆 (31.2%)`.
2. **Card 2 (Matches):** Measure `[Total Matches]`. Sub-label: `Games per Season`.
3. **Card 3 (Simulations):** Measure `[Total Simulations]`. Sub-label: `Full-Season Simulations`.
4. **Card 4 (Accuracy):** Measure `[Model Accuracy]` (formatted as `66.99%`). Sub-label: `Model Test Accuracy`.
5. **Card 5 (ROC-AUC):** Measure `[Model ROC-AUC]` (formatted as `0.732`). Sub-label: `Out-of-Sample AUC`.

### Visual 3: Monte Carlo Title Winners Bar Chart (Left Side)
- **Visual Type:** Clustered Bar Chart (Horizontal)
- **Y-Axis:** `fact_team_projections[TEAM]` (or `[FULL_NAME]`)
- **X-Axis:** `fact_team_projections[TITLES_WON]` (or `[CHAMPIONSHIP_PROB]`)
- **Filters on Visual:** Top 16 by `TITLES_WON` (Descending)
- **Bar Color:** Vibrant Solid Blue (`#1E88E5`)
- **Data Labels:** Turn **On** (Position: Outside End, Values: Whole Number or `0.0%`)
- **Title:** `Monte Carlo Title Winners (10,000 Full-Season Simulations)`
- **X-Axis Title:** `Sum of Titles`

### Visual 4: Championship Winning Probability Donut Chart (Center)
- **Visual Type:** Donut Chart
- **Legend:** `fact_team_projections[TEAM]`
- **Values:** `fact_team_projections[CHAMPIONSHIP_PROB]`
- **Filters on Visual:** Top 10 Contenders
- **Detail Labels:** Data value & percentage of total (`0.0%`)
- **Title:** `Championship Winning Probability`

### Visual 5: Dropdown Slicers
- **Slicer 1 (Conference):** `dim_teams[CONF]` (Horizontal tiles or dropdown: `All`, `East`, `West`)
- **Slicer 2 (Team):** `dim_teams[TEAM]` (Searchable dropdown)
- **Slicer 3 (Playoff Stage):** `fact_sample_bracket[STAGE]` (Dropdown: `All`, `First Round`, `Conference Semifinals`, `Conference Finals`, `NBA Finals`)

### Visual 6: Sample Postseason Simulation Table (Bottom Right)
Directly mirroring the match results table in the reference dashboard:
- **Visual Type:** Table
- **Columns:**
  1. `fact_sample_bracket[STAGE]` (Stage: First Round, Conf Semifinals, Conf Finals, NBA Finals)
  2. `fact_sample_bracket[HIGH_SEED]` (Home / Higher Seed)
  3. `fact_sample_bracket[LOW_SEED]` (Away / Lower Seed)
  4. `fact_sample_bracket[SERIES_SCORE]` (Series Result: e.g. `4-2`, `4-3`)
  5. `fact_sample_bracket[WENT_TO_GAME_7]` (Went to Game 7: `True` / `False`)
  6. `fact_sample_bracket[WINNER]` (Winner)
- **Conditional Formatting:** Background color on `WINNER` column with light gold or blue highlight.
- **Style Preset:** `Alternating rows` with dark blue header (`#1D428A`, white text).

### Visual 7: Right-Hand Branding & Methodology Card
A vertical container on the far right:
- **Image:** Larry O'Brien Trophy silhouette or NBA logo.
- **Methodology Callout:**
  > *"This dashboard presents the outcomes of 10,000 full 82-game regular season and postseason simulations. Built with leak-free pre-game Four Factors Logistic Regression (66.99% accuracy), empirical Bayesian shrinkage player ratings ($K = 8.0$), and Log5 matchup odds."*
- **Footer Quote:** `“Where Amazing Happens” — NBA`

## 5. Page 2: Regular Season & Play-In Dynamics (In-Depth)

A second page dedicated to the 82-game regular season and the Play-In tournament:

1. **Conference Standings Tables:**
   - East and West split tables showing: `Rank`, `Team`, `Proj Wins`, `Proj Losses`, `Playoff %`, `Conf Finals %`, `Finals %`, `Title %`.
2. **Seed Probability Matrix (Heatmap):**
   - **Visual Type:** Matrix
   - **Rows:** `fact_seed_distribution[TEAM]`
   - **Columns:** `fact_seed_distribution[SEED]` (Seeds 1 through 10)
   - **Values:** `fact_seed_distribution[PROB]` (Formatted as `0.0%`)
   - **Conditional Formatting:** Background color gradient from White to Dark Blue based on probability value.
   - **Insight:** Instantly shows which teams are lock top-4 seeds (Denver, OKC, NYK, Philly) vs. high-variance Play-In bubble teams (Golden State, New Orleans, Miami, Indiana).
3. **Win Distribution Box / Range Chart:**
   - **Visual Type:** Clustered Column or Error Bar chart
   - **Fields:** `fact_win_distribution[MEDIAN_WINS]` with error bars from `[P10_WINS]` to `[P90_WINS]`.
   - **Insight:** Demonstrates that a 50-win projection carries a real uncertainty range of 42 to 58 wins depending on schedule breaks.

## 7. Step-by-Step Power BI Desktop Build Instructions

1. **Open Power BI Desktop** -> Click **Get Data** -> **Folder** (or **Text/CSV**) -> Select `powerbi/data/`.
2. Load all 8 CSV files.
3. In **Model View**, verify the relationships match Section 1 above.
4. Create the `_Measures` table and paste the DAX formulas from Section 3.
5. Create Page 1:
   - Add a Shape (Rectangle) across the top for the title banner.
   - Insert 5 Card visuals for the KPI metrics.
   - Insert a Clustered Bar chart on the left for Title Winners (Top 16).
   - Insert a Donut chart in the center for Winning Probability.
   - Insert Slicers for Conference and Team.
   - Insert a Table visual for the Sample Playoff Bracket Series.
6. Apply styling:
   - Turn off background for charts, enable white background with 1px border (`#E2E8F0`) and shadow on cards.
   - Format numbers: percentages to 1 decimal place (`0.0%`), wins to 1 decimal place (`0.0`).
7. Save project as `nba_2026_27_prediction_dashboard.pbix`.
